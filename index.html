Four changes I'm proud of

The first is from my current role at Persistent Systems; the other three were built for a BFSI client at TCS. Traces, names and code samples are my own illustrations, not client data or code.

Names showing as raw IDs, caused by a silent AccessDenied

Symptom
On a commerce platform's recommendation feed, retailer and supplier names showed up as raw IDs.
Cause
An IAM AccessDenied error was caught and silently swallowed, so the lookup quietly fell back to IDs.
Fix
A Redis fast path, a batched OpenSearch fallback, a request timeout budget, and least-privilege read-only access across three Lambda roles.
Result
Names resolve again, fast from cache and with a bounded fallback.

Replacing static API keys with OAuth 2.0

Problem
Clients called APIs with static API keys, which are hard to rotate and easy to leak.
Work
Led the rollout of OAuth 2.0 with Amazon Cognito and API Gateway JWT authorizers.
Result
Short-lived, scoped tokens. Bad requests stop at the gateway.

Smaller Lambdas and encryption defined in code

Problem
AWS SDK v2 bundled the whole SDK into every function, and KMS keys were set up by hand.
Work
Upgraded to the modular SDK v3 and automated KMS keys, encryption policies and least-privilege IAM in AWS CDK.
Result
Smaller packages, faster cold starts, repeatable security.
