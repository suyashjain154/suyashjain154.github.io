OAuth 2.0 replaces API keys

Problem
Clients authenticated with static API keys, which are hard to rotate and easy to leak.
Work
Led the rollout of OAuth 2.0 with Amazon Cognito and API Gateway JWT authorizers.
Result
Token-based, scoped access across the API estate.
CognitoJWTOAuth 2.0IAM

Smaller packages, faster cold starts, repeatable security.
